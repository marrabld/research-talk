# From Satellites to AI

An interactive research seminar by Dr Daniel Marrable, Director of Innovation Central Perth, Curtin University and Cisco.

**[Open the presentation](https://marrabld.github.io/research-talk/)**

Use Next, Previous or the arrow keys to move between slides. Animations start automatically and can be paused, replayed or revisited through their chapter menu. Devices requesting reduced motion open animations paused.

The story follows PhD optical measurements, early GPU particle-scattering work using GLSL, European satellite projects, parallel computation, AFID commercialisation and current multimodal AI concepts.

The HTML file is self-contained and can also be downloaded for offline viewing. It contains no speaker notes. The animations use teaching illustrations, not original project datasets or reported validation statistics.
